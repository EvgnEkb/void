# BUGFIX: Некорректный расчет НДС

## 1. Найденная ошибка

В методе `BillingService::calculateInvoiceAmount()` НДС считался от исходной `$basePrice`, а не от `$currentPrice` после применения скидки лояльности и купона.

Это нарушает порядок бизнес-логики:

1. Базовая стоимость
2. Скидка лояльности
3. Купон
4. НДС на сумму после всех скидок
5. Минимальный порог
6. Защита от отрицательных значений

### Было

```php
$taxAmount = $basePrice * ($vatRate / 100);
$currentPrice += $taxAmount;
```

### Стало

```php
$taxAmount = $currentPrice * ($vatRate / 100);
$currentPrice += $taxAmount;
```

### Использование float для денег
Деньги нельзя хранить и считать в float. Это приводит к ошибкам округления и финансовым расхождениям.

Нужно использовать:

целые числа в минимальных денежных единицах, например копейки/центы;

либо Value Object Money;

либо decimal-тип, если он доступен в языке/фреймворке.
